# My UNA World 1.3.5 candidate

My UNA World remains free. This candidate has a full installer and native
updaters from exactly 1.3.3 and exactly 1.3.4. It supersedes the earlier 1.3.4
maintenance-controls candidate without changing that candidate's ZIPs or updater.

## Changes

- Backups displays Started, Completed and Duration in UTC, with an explicit
  Not recorded value when historical evidence is unavailable.
- Completed verification sidecars record phase durations and slowest database
  tables after archive finalization, integrity checking and checksum generation.
- Active backups show elapsed duration and throttled database table/row progress.
- Recovery controls remain grouped and retain CSRF protection, typed restore
  confirmation and protected rollback-backup handling.
- Restore preserves My UNA World's 1.3.5 module registration. Overview displays
  the actual registered module version.
- Maintenance presentation controls and Visitor Gate behavior remain available.

No database schema change or SQL export/restore algorithm optimization is included.
Existing backup archives are preserved. Reporting/submission features are outside
this release.

| `My-UNA-World-Update-1.3.4-to-1.3.5.zip` | `update_1.3.4_1.3.5/` | 1.3.4 → 1.3.5 |

The installer contains the runtime, current installation resources, approved
Studio icons and user instructions. Development tests, repository metadata,
release records and previous ZIPs are excluded. Each updater contains its native
installer/configuration and the complete changed runtime payload: Backup,
BackupTiming, Db, Module, Restore, StudioPage, status.php, install/config.php and the native Studio icon at
`template/images/icons/std-icon.svg`. The icon backfill repairs older installations
that contain only studio-icon.svg in that directory.
Updater installation enables file replacement and cache clearing; SQL and
language updates are disabled because neither is required.

The package manifest records the exact source commit/tree, included file hashes,
package sizes and SHA-256 values. ZIP timestamps, ordering and modes are fixed
so rebuilding from the same source produces identical bytes.
