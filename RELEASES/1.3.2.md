# My UNA World 1.3.2

## Release purpose

Version 1.3.2 establishes **MyUNAWorld** as the official vendor identity for My UNA World while preserving all compatibility-sensitive technical identifiers.

## Identity

- Product: My UNA World
- Module name: `my_una_world`
- Version: `1.3.2`
- Vendor: `MyUNAWorld`
- Module path: `newton/my_una_world/`
- Class prefix: `MyUnaWorld`
- Database prefix: `my_una_world_`
- UNA compatibility declaration: `15.0.x`

## Source changes from 1.3.1 FINAL

Only these runtime/release files changed:

1. `install/config.php`
   - Version 1.3.1 → 1.3.2.
   - Vendor NewtronJax → MyUNAWorld.
2. `classes/MyUnaWorldRestore.php`
   - Current tool version → 1.3.2.
   - Vendor verification → MyUNAWorld.
   - Registration self-heal now restores `sys_modules.vendor` to MyUNAWorld.
   - Same-site restore version message → 1.3.2.
3. `classes/MyUnaWorldStudioPage.php`
   - Studio displayed module version → 1.3.2.
4. `README.txt`
   - 1.3.2 release identity and notes.

Backup, restore, rollback, retention, lifecycle protection and background-worker behavior are otherwise unchanged from the verified 1.3.1 FINAL baseline.

## Native UNA updater

Updater path in source control:

`updates/1.3.1_1.3.2/`

The distributable updater is packaged with top-level directory:

`update_1.3.1_1.3.2/`

Its source payload reuses the exact 1.3.2 Git blobs for the four changed files. Its SQL migration is intentionally limited to:

```sql
UPDATE `sys_modules` SET `vendor` = 'MyUNAWorld' WHERE `name` = 'my_una_world';
```

No database schema changes are required.
