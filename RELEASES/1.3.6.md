Full backups now activate UNA's native public maintenance gate before exporting
data. Studio and administrator access remain available. The existing settings
choose the branded World page or the site's configured maintenance page; either
choice blocks public requests during a full backup. Inventory tests stay online.

The prior release saved presentation settings without activating maintenance.
That missing operation boundary is corrected in createBackup(), which covers
queued manual backups and synchronous lifecycle/safety backups. This record
does not claim maintenance coverage for the entire restore operation.

maintenance, restores exact owned settings on completion/error/shutdown, and
permits cron recovery only after the active process releases its lock. Native
conditional SQL and ownership markers preserve concurrent administrator edits.
Backup SQL records the original maintenance options, rather than the temporary
lockout, so a restored snapshot retains the original access state.

packages remain immutable and provide the earlier steps in the supported chain.
The full installer remains free. GitHub tags/releases/assets are unchanged.
