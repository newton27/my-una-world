## Icon acceptance gate for subsequent releases

Check the installed UI after both a fresh install and a native update. Every Studio menu entry must show an actual glyph or a successfully loaded image, including active and inactive states. Check image `naturalWidth` and resolved paths, and check font pseudo-element content; an element's width alone does not prove its icon is visible. Verify the launcher and Apps information popup as well. Record screenshots and the package/source identity before marking icon acceptance complete. Keep this gate separate from PHP syntax and package-path checks, which did not detect the missing font glyph.
